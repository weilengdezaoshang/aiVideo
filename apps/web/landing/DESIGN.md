# 帧屿集介绍页

仅作用于 web/landing。面向初次访问的创作者，以理解产品并进入工作台为目标。用户指定沿用 Logo、黑白主题，保留上一轮减少文字与图片噪声的要求。

## 当前设计

居中首屏：一个产品定位标题、一句说明、一个主按钮。随后是唯一的产品展示面板，以图像生成、图片加工、图生视频三个 tab 按需展示内容，始终只保留一张参考图片。下方三个短说明对应画布编排、精细加工与保存。没有图库、轮播、长流程或模拟聊天。

Logo 直接复用 ../brand/ SVG，保留纯黑轮廓。背景 #f5f5f3，文字 #171918，次要文字 #646662，面板 #ececea，分隔线 #d6d7d2。主按钮 6px 圆角，展示面板 12px。没有装饰阴影或渐变。

字体为本地 Frayune Sans（Noto Sans CJK SC Medium 页面字形子集；assets/frayune-sans-OFL.txt 保留许可证），系统字体回退。标题 42–64px，正文 13–15px，辅助说明 10–12px。

## 功能真实性与响应式

文案依据 README 及已有产品功能。加工选框仅为示意，视频使用静态首帧参考，不伪造生成结果或视频播放。示例图片复用 architecture.jpg，标注参考素材。所有创作入口进入 /workspace。

宽度最大 1120px，600px 以下单列。tab 支持左右方向键、Home、End、aria-selected 与 roving tabindex；静态默认面板在 JS 不可用时仍能阅读。保留可见焦点、跳至内容和 reduced-motion。

## 生图与视频定位、动效补充

首屏明确 AI 图像与视频创作。生图进入工作台，视频探索按钮选择视频面板并滚动定位。相关能力改为原生 details，包含参考图、局部重绘、抠图、视频任务、下载与素材管理，默认折叠以控制噪声。

功能切换使用 240ms ease-out 的 opacity/translateY 反馈，正在播放的过渡从当前视觉状态接续；按钮按压缩放 160ms，hover 位移仅限精确指针。视频面板提供 4 秒镜头缩放演示，可播放、暂停与拖动；显式标注静态图示意，不作为 AI 视频产物。切换、离开或隐藏页面停止播放；减少动态偏好不缩放、不执行面板入场。没有新增依赖。

验收：播放/暂停、进度终点、切换复位、原生功能展开和手机宽度通过浏览器检查。完整项目 verify 通过，163 项测试通过。

## 即梦官网参考后的当前视觉（优先于上述浅色规则）

用户要求参考即梦官网。实际查看 https://www.jimeng.com/ 的品牌介绍页及 https://jimeng.jianying.com/ 的产品首页。采用其影像优先、首屏少文案和后续功能展示的组织方式；不使用即梦品牌、文案或媒体资源。

当前页面改为黑白深色：背景 #101110、正文 #f5f5f3、辅助文字 #a3a69f、面板 #191b18、边线 #323530。首屏全屏本地灰阶照片，加固定透明度黑色遮罩保证白字可读。现有 FRAYUNE 字标保留。海面/建筑/光影三种参考图按点击切换，decode 后更新并带 420ms 过渡，序号取消过时请求；无自动轮播。首屏与视频演示都不冒充真实生成结果。

首屏之后保持单一功能面板与折叠功能说明，避免重复图库。手机改为横向场景按钮和底部双入口；动画遵守减少动态偏好。原生跳至内容入口使用独立黑底，保证深色主题可读。

## 彩色作品展示（当前优先规则）

用户反馈纯黑白无法体现图像与视频效果。界面、Logo、按钮继续采用黑白中性色，所有首屏与功能图片恢复原始彩色；移除 grayscale 滤镜，首屏遮罩由 52% 降为 28%，保留图片的色彩与光影。同步移除黑白摄影描述。现有视频仍明确为静态参考图的镜头示意，不以颜色调整冒充真实生成视频。此次为展示样式与文案修改；浏览器确认彩色首屏，脚本 lint 与 diff 检查通过。
