# 批量生成与可编辑分层

## 执行契约

`for_each` 是规划控制工具。主管一次返回输入集合与任务模板，编译器展开成普通 `tN` 步骤；稳定的项目/局部步骤标识保存在 `stage_key`，完整展开结果保存在 `core_plans.expansion_rules`。恢复读取已冻结结果，不再调用 Planner。展开后的全部步骤经过现有参数、类型、意图审核和整体报价检查。

普通计划继续使用主管的任务上限；批量计划受 `AIVERO_BATCH_MAX_BATCH_INPUTS`、`MAX_RULE_STEPS`、`MAX_SIZES`、`MAX_EXPANDED_TASKS`、`MAX_EDGE_PX`、`MAX_RULE_BYTES` 限制。单轮派发、单 Run 并发、全局并发分别由 `MAX_PER_BATCH`、`MAX_PER_RUN`、`GLOBAL_CONCURRENCY` 配置。恢复扫描上限为 `RECOVER_LIMIT`，以上均使用 `AIVERO_BATCH_` 前缀。

全局槽位存于 `core_batch_quotas`，跨进程共享。`GLOBAL_CONCURRENCY` 初始化该行的上限；已有行保持持久化上限，运维调整需在事务中更新 `limit_value`，且不得低于当前 `inflight`。取锁使用非阻塞方式，忙碌时下一轮重试。任务终态与结算释放槽位；取消结束的 Run 也由恢复扫描回收终态任务槽位。提交结果未知的任务继续占位，等待执行层对账，不能重新提交。

单项失败只取消其依赖后继，其他项目继续。全部任务结束后，含失败的 Run 保留失败状态；进度区分成功项目数与已结束项目数。`blocked_by_model` 不开放重做。中间产物保留历史和血缘，只有最终步骤写画布。

## 失败项重做

`POST /api/core/runs/{root_run_id}/batch-retry` 接收 `request_key` 和可选 `item_ids`。同一请求键幂等；仅允许当前已确认可重试的失败项。创建带 `parent_run_id` 的子 Run，复用成功前缀的自有资产，冻结规则任务书，交给同一个主管审核和工人执行。它不重新调用大模型，不重做成功项目。

父 Run 在同一事务分配积分、token 与思考轮次余额，防止并发重试超预算。子 Run 结束后幂等汇总结算，根 Run 展示有效项目进度，原计划与历史状态保留。未知 token 用量保守保留预算。

## 确定性排版与分层

`text_layout` 使用版本锁中的字体文件、哈希、尺寸及区域配置生成独立文字资产。字体缺字或文字溢出明确失败，不换字体、不让生成模型画字。默认字体为随代码分发的 Noto Sans SC，许可证及固定来源见 `core/composition/fonts/`。

`compose_layers` 将背景、可选透明主体和文字层合成为预览，并持久化完整层清单。预览只渲染一次，文字保持独立对象，可修改、保存、撤销和重载。组的移动与缩放同时作用于子层；按统一比例缩放，保留主体比例。每次生成追加 Asset 版本，不覆盖原图。

一图多尺寸通过锁定的尺寸预设重新布局背景、主体与文字。主体采用 contain 放置，不裁切主体。不能从普通平面图片凭空恢复真实图层；需要透明主体时先执行识别与抠图。未绑定的扩图能力仍明确不可用，不替换用户指定背景。

## 版本与验证

迁移 `0027` 增加配额、派发和重试收据；提示词新增 `supervisor-v2`，旧版正文与旧 Run 版本锁保留。生成能力仍从统一工具目录导出，只有工人调用本地确定性工具和生成接口。

单元测试覆盖展开、预算、依赖隔离、尺寸、字体、分层与画布历史；PostgreSQL 集成覆盖并发配额、重试准入、真实本地合成与事件重放。CI 的批量分层步骤仅使用假服务商和本地工具，不读取付费凭据。
