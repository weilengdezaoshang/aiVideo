# 帧屿集：GitHub Pages 与 README

## 范围与方向

为开源项目访客提供完整项目展示页，从理解产品到本地安装；README 共用品牌视觉，保留现有安装、API、迁移与时间线说明。仓库尚无 Pages 入口，新增独立静态站点 `website/`，不改变应用内落地页。

比较两个方向：深色全屏电影展厅强调作品，但难以快速读懂开源项目；浅色编辑式排版配深色画布同时容纳作品和安装信息。本次选择后者。主要手法是宽幅影像与大字标题形成对照，橙色只标记行动和序号。

逻辑视口：桌面 1440×900，手机 390×844。完整文档约 3000px 高，不将长页当手机海报。颜色：纸白 #F7F7F2、墨黑 #20231F、次级灰 #62665E、线条 #DADDD3、橙色 #DA542D。系统中文黑体与 sans-serif，等宽字用于章节编号和命令。内容宽度 1200px，间距基于 8px。

## 区块

1. `top`：品牌导航，功能、工作流、开始使用、GitHub。
2. `intro`：大标题“让灵感，成为下一帧。”，本地运行与源码入口；宽幅品牌影像。
3. `features`：图像、画布、视频三项能力，准确区分真实功能和概念素材。
4. `workflow`：从提示词到生成、画布整理、时间线导出的顺序。
5. `start`：完整本地启动命令，Mock 与真实 Provider 边界。
6. `resources` / 页脚：使用文档、接入说明、贡献和 MIT。

## 素材与实现

复用现有 logo、建筑与海洋图片；图片为品牌视觉参考，不声称是实时生成结果。生图用于布局设计稿，不将整页图片当实现背景。文字、导航、按钮、命令与折叠说明由语义 HTML/CSS 实现，本站无动态业务逻辑，不新增 JavaScript。素材复制至站点相对目录以兼容 GitHub 项目子路径。

README 使用站点首屏的浏览器截图作为品牌封面，图外保留可访问标题、链接与安装命令。详细说明保留原文；收拢首屏重复信息并提供目录。

手机取消多栏，标题随宽度缩放，命令区域独立水平滚动，导航允许换行。提供跳转正文、键盘焦点与减弱动态支持。所有主要操作均使用实际链接或原生 details。

## 验证计划

完整页面与手机截图；检查图片加载、横向溢出、锚点、文档链接及静态发布路径。运行 npm run verify，区分本次变更问题与工作区已有问题。静态页面不启动生成 API。发布工作流仅上传 website 目录，不包含配置、密钥或 data。
