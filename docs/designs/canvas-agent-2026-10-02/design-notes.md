# 画布 Agent 形态设计稿

本轮仅交付静态设计稿，用于讨论产品形态，不修改应用。

- 场景：为客厅原图左侧添加落地灯，检查低成本预览，再局部修正。
- 三个状态：01 画布预览待确认；02 在同一预览上涂抹并补充指令；03 对话输入框的模型图标展开菜单。
- 桌面逻辑视口：1440 × 900；生成目标比例 16:10，实际像素以生成文件为准。
- 沿用现有浅色设计：#F7F8FA 点阵画布、#FFFFFF 工具表面、#24262B 正文、#737987 次级文字、#DFE1E6 边框、#3478F6 主操作。字体使用 Inter 与系统中文无衬线。
- 空间：左侧工具条、中央无限画布、右侧约 360px 文档对话。手动生成框仅位于中央画布底部。
- 预览置于原图右侧；对话显示同一结果的缩略图和「就用这张 / 这里要改 / 停」。原图不改。
- 修改状态仅收集涂抹与文字，发送前不重新生成。
- 模型图标菜单按图片与视频分组；示意「自动选择」与命名模型条目，不添加比例、时长等第二套表单。模型名称只用于界面示例，不代表已配置能力。
- 已确认结果自动带入下一轮可移除引用；切换选中对象不暗中替换引用。本组主场景为待确认预览，不表现为已确认。
- 布局、文字、图标、按钮、引用标签、菜单和蒙版覆盖层应由原生组件实现；室内摄影为独立素材。当前整图为设计稿，不可作为页面背景替代实现。
- 连续视频、草图与 SVG 的专项状态留待后续，不在这组三张中完整展示。
- 菜单严格指定模型的行为仍是建议；本组只展示入口和分组，不视为已定产品规则。
- 未验证：真实交互、响应式、模型能力、实际费用和预览升正式的一致性。

生成方式：内置 imagegen；后续状态以首张设计稿为视觉参考。提示词与生成记录一并保存。
