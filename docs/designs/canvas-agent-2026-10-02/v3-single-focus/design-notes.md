# 单一输入焦点 · v3

根据「两个对话框会让重点难以突出」的反馈，调整默认入口层级。保留既定画布与右侧文档对话，手动生成按需展开。

- 默认：右侧对话是唯一可见文本输入区。底部大手动生成卡收起，在缩放工具旁保留轻量「手动生成」按钮。
- 点击「手动生成」：展开独立的手动参数面板，同时暂收起右侧输入区；对话记录、待确认卡和运行状态仍可见，不取消任务。
- 关闭手动面板或选择返回对话：恢复原对话输入、草稿及引用。两边草稿分别保留；切换不提交生成、不替代确认、不改变引用。
- Agent始终位于右侧文档对话，不进入底部生成框；模型菜单维持图标入口，预览的三个确认动作不变。
- 本图只展示默认状态；手动面板展开及焦点恢复的实际交互尚未验证。
- 延续v2的1600×1000逻辑视口、浅色配色和「雨后漫步」素材。保留v2作对照，不覆盖旧稿。
