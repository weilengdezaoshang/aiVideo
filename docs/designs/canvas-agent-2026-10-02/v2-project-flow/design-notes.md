# 画布 Agent · 项目交互设计稿 v2

仅交付静态效果图，用于优化产品形态，不修改业务代码。沿用v1浅色设计，缩小底部手动框的视觉体量，补全多素材到视频的项目交互。

## 共用设计
- 文档「雨后漫步」；主体「小雨」是黄色雨衣、深色短发、米白帆布包的成年女性；草图「草图 01」，场景为雨后咖啡店外。
- 桌面逻辑视口1600×1000，生图目标16:10，实际尺寸见生成记录。
- 白色顶栏、60px左工具栏、390px右侧文档对话、浅灰点阵画布。沿用#F7F8FA、#FFFFFF、#24262B、#737987、#DFE1E6、#3478F6。Inter与系统中文字体。
- 黄色雨衣和雨后街角的冷暖摄影是视觉重点。对象附近放操作工具，选中结果才显示素材来源线，不要求用户搭建参数节点图。

## 四个状态
1. 发送前：主体图与16:9草图分开，输入框两枚可移除引用分别注明主体/构图；风格写在文字里；技能菜单在同一输入框展开。铅笔、钢笔共用草图。
2. 生成后：一张低成本图片预览放在草图右侧，来源线区分主体/构图；对话只给「就用这张 / 这里要改 / 停」。本图不混入局部修改待发送状态，后者已在v1展示。
3. 用户确认图像并另行要求连续视频后：可见已确认首帧；仅第一段有低成本视频样片；第二段为空白等待位。仍用三个按钮确认，不能以输入「继续」代替。
4. 后续独立状态：各段预览已确认且正式视频已完成，用户说「把这两段接到时间线」；底部打开结果时间线，按序两段视频，无第二个Agent输入框，无自动配音、字幕轨道。

## 交互与实现边界
- 选中对象不自动引用；标签带用途、名称、缩略图和移除按钮。已确认结果自动作为下一轮显式引用。
- 主体与构图分别输入；草图不控制画风，框外笔画不参与。原始素材保留。
- 「这里要改」进入标记并等待补充，未发送不生成；不出现计划卡、四候选、另一个Agent入口。
- 底部手动生成框始终独立；时间线展开时它上移到画布剩余区域。模型仍是输入框图标，本轮不展开未拍板的模型选择策略。
- SVG精确矢量编辑不在本轮四张中展开，保持既定规则。
- UI文字、控件、引用、来源线和时间线应由交互组件实现，摄影是独立素材；本轮整图不可作为实际网页背景。

## 待验证
静态图不证明视频连续性。若正式版重新生成，正式第一段末帧可能不同于已确认预览，进而影响后续段。模型能否保持已确认内容仅增强分辨率、或是否需补充正式链确认规则，仍需验证；本组不承诺「无缝高清重生成」。
图中时长/清晰度是交互示例，不代表当前模型配置；真实交互、窄屏、刷新恢复、并发手改冲突未验证。

生成使用内置imagegen。01引用v1设计系统；检查后02–04共享01为基准，保留首轮样本、提示词和检查记录。
