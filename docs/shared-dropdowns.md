# 项目公共下拉菜单

公共实现位于 `web/shared/`，以画布用户菜单的背景、12px 圆角、边框、阴影和悬停态作为统一基准。

- `dropdown.ts`：选项组合框。接收原生 select，统一渲染触发按钮、浮层、选项与选中标记；沿用 value/change 接口，支持程序设置值、禁用、动态选项以及释放监听。
- `action-menu.ts`：接入现有 details/summary 动作菜单，统一外部点击、Esc、方向键和菜单互斥；普通 FAQ 折叠面板不属于下拉菜单。
- `menu-navigation.ts`：共用键盘导航和禁用项跳过规则。
- `dropdown.css`：两类菜单共同的视觉样式，跟随项目主题变量。
- `init-dropdowns.ts`：页面静态菜单接入入口。动态节点面板调用 createDropdown，并在释放时 dispose。

已接入画布用户菜单、缩放菜单、对话栏添加/技能/引用菜单、创作模式与尺寸、设置的生成后端和云端厂商、视频时长弹窗，以及图片/视频占位面板全部选择项。当前工作台和介绍页没有下拉菜单，未来新增时使用同一组件。

设置页已移除 sl-select，保留其他 Shoelace 弹窗和输入框。组合框焦点留在触发器，通过 aria-activedescendant 标识当前选项，避免模态弹窗抢走选项焦点。浮层使用 Popover 顶层，不受面板滚动裁切。

浏览器验证使用独立 Mock 数据：设置后端方向键选择及关联配置区域更新、图片比例键盘选择、选择后关闭并保留触发器焦点。没有保存测试设置或调用生成服务。
