以最新 PRD 为准。工作台入口层级与无限画布 + Agent 重心已明确；PRD 中的“建议”继续保留建议性质。旧稿的角色、商品、分镜、复杂图层合成与其他工具，不自动加入本版。

即梦参考与本稿取舍

参考于 2026-09-08 查看过的即梦工作台：借鉴左侧窄导航、中央创作输入区，以及参数集中在输入区下方的结构。Tab 在本稿落为左侧导航项；图片、视频名称沿用当前 PRD。

编辑器参考即梦官网的智能画布展示中简洁顶栏与大面积画布，再按用户最新确认配置四个悬浮图标、底部输入框和右侧对话栏。实际画布管理页需要登录；本稿的管理卡片、空态和 Agent 流程依据 PRD 绘制，不标为即梦现有交互。

首版以画布创作为重心。首页快捷生成仍为建议；即梦的社区、活动、会员和未纳入 PRD 的创作工具不作为本版功能。

生成状态参考补充（2026-09-09）：当前即梦官网的生成记录需登录，未实测新版的生成等待过程。公开教程中的旧版智能画布截图展示了压暗处理画面及明确的“图片生成中…”反馈。本稿借鉴状态与图像预览分离的表达，按已确认的一次任务同时生成四张规则展示整组占位；加载环和灰度方案是本稿提案。

此文档是桌面应用线框。手机可纵向阅读说明，横向滑动每张画面；不是产品移动端设计。名称与对象均为示例数据。
