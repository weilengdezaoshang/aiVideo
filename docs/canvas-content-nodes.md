# 内容节点实现

双击空白画布打开文本、图片、视频菜单；菜单初始没有选中项。新建后选中对应节点。仅单击尚无内容的图片/视频占位节点显示生成面板；已有媒体显示原有操作栏，单击文本显示背景色、编辑、展开、下载工具栏。文本双击进入原位编辑，空文本卡片也会保留。图片双击保持选中；已有视频双击播放。AI 对话仍在右侧对话栏。

## 前端边界

- `state/node-model.ts`：稳定 image/video/text 类型、独立 nodeDraft、nodeRun、旧 draft 迁移、结果绑定校验。
- `flows/create-menu.ts`：双击菜单和节点创建，不默认高亮文本。
- `flows/node-panel.ts`：选中对象上下文面板、上传/画布参考图、参数草稿、文本工具栏；面板随视口定位，空间不足时调整视口。
- `flows/node-generation.ts`：提交、取消、SSE、刷新对账、取消 outbox。每次生成绑定 documentId + clientRef + requestId。
- `engine/node-appearance.ts`：空媒体状态和渲染重建签名。
- 现有 `app.ts`、`object-layer.ts` 负责整页接线与对象层，接入上述模块和已有选择/文字编辑逻辑。

双击新建时使用固定画布尺寸：图片和文本为 320×320，视频为 480×270；屏幕显示尺寸等于元素画布尺寸乘以当前缩放，不按缩放反向补偿；选中媒体占位元素不再自动缩放或平移视口。生成面板默认宽 720px，窗口不足时收缩；下方空间不足时优先显示在节点上方。画布显示尺寸独立于生成分辨率。首次结果原位回填；已有结果通过原有对话和右键操作继续创作，不弹出节点生成面板。当前每次一个结果，单张参考图；视频采用首帧参考。上传限制为 8MB PNG/JPEG/WebP。

## FastAPI 接口

| 接口 | 用途 |
| --- | --- |
| GET /api/generation-capabilities | 返回实际 Provider 支持的模型、参考图、比例、分辨率和视频时长 |
| POST /api/generate | 沿用生成 API，新增 documentId、clientRef、requestId、referenceAssetIds |
| GET /api/generation-requests/{requestId}?documentId=... | 按请求查询状态，支持刷新/断线恢复 |
| DELETE 同一路径 | 取消已接受任务或提前登记取消，阻止迟到提交 |

同一请求重复提交返回原任务，更改参数返回 409。取消记录先落盘；请求绑定任务不会随普通历史任务的 200 条裁剪被清除，防止重复生成。无 requestId 的原有调用保持原协议。当前仍使用单进程 JSON 存储；长期运行的绑定任务快照会增长，后续可归档为独立请求索引，但不能直接删除去重记录。

队列和事件包含节点绑定字段。客户端必须同时匹配三个 ID 才能回填；删除/撤销提交会取消任务，重做仅查询状态。网络异常保留结果待确认状态，不自动发起新请求；手动确认重用原请求 ID。服务重启中断的任务显示失败，用户显式重试才创建新请求。

文档保存复用原 Documents API，nodeDraft/nodeRun 随对象持久化，切换节点不共享提示词。运行中参数是提交时的快照。文本仍为普通文档数据，不经过生成队列。

## 能力范围与验证

Mock 支持图片及演示视频；当前云端适配器尚未实现视频，界面禁用视频提交并提示原因。ComfyUI 视频仍要求服务端安装/配置相应模型。未实现主体库、音频时间线、多参考视频或积分展示。

自动测试覆盖独立草稿、旧节点迁移、跨文档/节点/请求迟到结果隔离、撤销/重做取消、参考资产读取、重复提交、重启去重、提前取消和能力校验。浏览器使用临时 Mock 数据验证图片与视频生成、画布首帧引用、文本编辑、刷新恢复、对话栏共存及 1280×720 面板定位。未调用付费模型或真实 ComfyUI GPU 推理。
