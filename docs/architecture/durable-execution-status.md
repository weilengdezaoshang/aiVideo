# 生产后端改造：实现与验收状态

状态：实施中。核心持久化执行与独立生产 API 已实现，但仍不能声称原方案所有验收项完成。
默认开发入口保留旧模式；新生产入口需要显式 AIVERO_API_MODE=production，不得双调度运行。

## 已实现

- PostgreSQL migrations 0002–0008：阶段、固定期限、租约/epoch、Attempt、批次、会话/成员、资产、审计、媒体别名和取消墓碑。
- 事务受理：幂等重放优先，全局/工作区/用户容量，Outbox 积压限制；任务与事件同事务。
- 批次独立子任务和父聚合；四方向组图原子受理、独立 clientRef 和进度。
- Provider 固定快照、实际模型解析、凭据引用；准备/提交/查询/取消/下载独立阶段。
- 不明确提交进入 unknown，不自动重提，名额保留；已有上游句柄只能查询原任务。
- Worker 原子领取、独立心跳、租约恢复、迟到写入 fencing；排队/执行/下载/对账各自固定期限。
- PG 模型并发名额；Redis 分操作限频、熔断、唯一半开探针、恢复渐进放量、跨操作凭据暂停。
- 产物收据、摘要校验、原子写入、失联恢复；数据库写入失败后恢复已有产物，不重新生成。
- 独立 Dispatcher、Scheduler、Bridge、通知进程；确认后 ACK，有限重投与审计死信恢复。
- 图像/视频/导出独立 Celery 队列；按阶段设置进程保护时限，FFmpeg 进程组回收。
- 数据库生产 API：任务、文档 revision、历史、资产引用、导出；不构造旧内存调度器。
- OIDC 签名/issuer/audience/nonce + PKCE、安全会话、CSRF、工作区成员逐请求授权。
- SSE 先订阅后快照、版本合并、断线轮询；Redis 丢通知时周期从 PG 对账。
- rembg 单推理线程，取消/超时不提前释放槽位；识别 mask 仅响应返回、不持久化。
- Pydantic 任务响应及生成 TypeScript 契约，测试检测漂移；同源前端变更请求附带 CSRF。
- 离线旧任务/文档/媒体导入、哈希和引用校验、审计；未知旧任务不自动调用上游。
- 管理员审计停止确认、恢复原句柄对账、凭据解除暂停；只读媒体校验和孤儿候选扫描。
- 非 root Docker 镜像含 FFmpeg、Compose 生产配置、基础 PG 聚合指标和 Prometheus 告警规则。
- 独立公共产物 HTTP 池：HTTPS、DNS 地址检查、连接已校验 IP 保留 TLS SNI；禁止私网/隧道地址和环境代理。
  ComfyUI 内部产物仅允许显式配置的同 origin；生成图片内容校验，供应商响应体限制 64 MiB。

- 最新全量 npm run verify：234 前端、300 后端测试通过，无跳过；类型检查、构建、ESLint、Ruff 通过。
  前端同时存在用户的架构迁移，测试数量随该工作变化，此处记录最后一次实际执行结果。

- Docker 镜像实际构建成功；UID 10001、FFmpeg 可执行、生产模块可导入。

- 一项第三方 Starlette/AnyIO 弃用警告。

测试后继续修复的部分仍需最终重新跑完整矩阵；上述记录不是最终版本验收签署。

## 剩余缺口，禁止作为已完成项

1. 旧 Agent、分镜编排/规划、评测等外围 HTTP 功能尚未全部迁入生产数据库链路。
   迁移器未覆盖这些记录及缺少原参数的文档创建幂等记录，不能直接替代启用这些功能的旧部署。
2. 真实 Provider 目前均保守声明不支持提交幂等/按请求 ID 查询。
   缺少句柄的未知提交需人工确认，不能借死信重放重新提交。
3. 外部媒体 DNS/IP 安全池与图片内容校验已实现，视频全容器探测及真实公网 TLS/CDN 故障验收仍待完善。
4. SSE 慢客户端、会话撤销和跨 API 订阅竞态的真实网络故障矩阵不完整；
   前端全部恢复状态展示仍需端到端验收。
5. 提交/落盘/ACK 全崩溃点、Celery 池级硬超时、基础设施故障、取消确认和半开失联等
   故障注入未全部完成；8 子进程测试不能替代这些验收。
6. 孤儿扫描只报告、不自动删除；带保留期和审计的回收仍待实现。
7. 已执行小规模数据库/媒体配套恢复，持续自动化恢复、增量回退及大数据量演练未完成。
   真实 OIDC、TLS 和告警接收方需要部署配置验收。
8. 基础日志/指标不等于完整分布式追踪、阶段延迟直方图；
   模型列表当前为固定路由列表，没有远程 stale 缓存链路。
