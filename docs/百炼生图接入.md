# 百炼 qwen-image-2.0 文生图接入

## 当前支持范围

已接入百炼同步文生图协议：提示词 → POST 原生接口 → 解析图片地址 → 下载 → 本地图片与历史记录。图生图、局部重绘、视频未在此适配器中启用，不会静默切换其他计费模型。

配置检查只确认本机 Key 已配置，不会发生成请求，也不能证明 Key 有效或存在免费额度。真实验收必须实际生成图片。

## 最短启动方式（推荐）

```bash
npm run bailian
```

首次运行按提示输入 Workspace ID 和 API Key；Key 输入时不会显示，也不会进入 shell 历史。脚本直接启动 `qwen-image-2.0`，默认地址为 <http://127.0.0.1:7802/canvas/>。本方式不保存 Key，服务停止后下次启动需要重新输入。

如果希望保存本机配置、下次无需输入，再使用以下方式。

## 1. 本机填写配置（可选）

在项目根目录执行（目标文件不存在时才复制）：

```bash
cp -n .env.bailian.example .env.bailian.local
```

用自己的编辑器打开 `.env.bailian.local`，填写两项：

```dotenv
SWARMUI_CLOUD_BASE_URL=https://你的业务空间ID.cn-beijing.maas.aliyuncs.com/api/v1
SWARMUI_IMAGE_API_KEY=你的百炼普通APIKey
```

其余保持模板值：`cloud`、`aliyun`、`qwen-image-2.0`、端口 `7802`。可以粘贴完整的 `/api/v1/services/aigc/multimodal-generation/generation` 地址，代码也能识别。不要把 OpenAI 兼容 `/compatible-mode/v1` 地址用于这个原生接口。

业务空间 ID 在百炼控制台右上角当前业务空间详情/业务空间管理中复制。Key 与地址必须属于同一地域；普通百炼 API Key 与订阅专用凭证不要混用。

`.env.bailian.local` 已被 Git 忽略，但不是 AI 权限隔离。不要把 Key 发到聊天中。若在网页设置输入 Key 并保存，现有机制会写入 `config.json`，因此此次推荐仅在本机环境文件填写 Key，不用网页保存密钥。

## 2. 启动

需要 Node.js 20.6+（推荐当前 LTS）。首次克隆先执行 `npm ci`；已有依赖可跳过。

```bash
npm run start:bailian
```

此命令加载 `.env.bailian.local` 并启动服务，不需要再手动 export。已有 shell 环境变量优先于文件；若配置没有生效，检查之前手动设置的 `SWARMUI_*`，不要打印整个环境或密钥。

看到 `provider=cloud` 才是云端模式。打开 <http://127.0.0.1:7802/canvas/>。仅监听本机地址；此开发服务没有面向公网的认证，请勿直接公开。

若提示 `EADDRINUSE`，在原服务终端 Ctrl+C 后重启，或把模板的端口改成空闲端口。修改环境文件后需重启，网页保存不会覆盖已有环境变量的生效值。

## 3. 生成一张图片

1. 打开设置，确认厂商是“阿里云百炼”，模型是 `qwen-image-2.0`，已配置图像 Key。无需再次填写或保存。
2. 选择文生图，不上传参考图或蒙版，尺寸先设 `1024×1024`，数量为 1。
3. 输入“一只橘猫坐在窗边，柔和自然光，摄影风格”，点击生成。
4. 等待图片显示，打开原图或下载，刷新页面确认历史仍存在。

成功标准：任务 completed、有实际可打开的图片、本地历史可恢复，并且百炼控制台能看到相应调用。Mock 占位图、配置检查通过、自动化桩测试都不等于真实模型成功。

免费额度以账户控制台为准；调用前确认目标模型额度及有效期，并在百炼为目标模型开启免费额度用尽停止调用（若账户支持），确认其生效。应用本身不会自动阻止免费额度用尽后的计费。先只生成一张，不批量重试。

## 4. 排错

| 情况 | 检查 |
| --- | --- |
| 未配置 Key | 本机文件是否填好，是否用 start:bailian 启动 |
| HTTP 401/403 | Key、地域、业务空间和模型授权 |
| HTTP 404 / 非 JSON | 接口地址是否为百炼原生地址 |
| HTTP 429 | 限流或额度状态，停止连续重试 |
| 参数错误 | 模型名、尺寸，先用 1024×1024 |
| 图片下载失败 | 返回图片的存储域名是否可访问；生成可能已计费，先检查任务再重试 |

采样器、步数、CFG、重绘幅度不传给此文生图接口。反向提示词与范围合法的种子会传递，图片数量由项目任务队列控制，单次上游请求固定为一张。
