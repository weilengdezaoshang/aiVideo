首版必须完整走通的路径

介绍页→工作台→我的画布→编辑器→生成与抠图→保存、下载、再打开
  • 四张是一组：同一任务、四个创意方向、四个同时出现的占位；正常终结后整组发布。
  • 蒙版不是结果：用户检查保留区域，点击蒙版栏“抠图”后才生成透明素材。
  • 来源不会断：派生结果紧邻源图，四候选尺寸不变；画布与对话引用同一资产。
  • 恢复不会重做：刷新查询原任务；结果未知不盲目重提，重复事件不重复插入。

三项推荐，待负责人审阅

  1. 首条 Agent：引用一张图，准备蒙版，经用户提交生成透明结果并落位。
  2. 视频范围：先复用已验证的生成入口，打通资产导入、预览与原文件下载。
  3. 技术路线：复用现有 JS + Konva 画布，引入 Python 任务核心与持久化，分阶段迁移。
