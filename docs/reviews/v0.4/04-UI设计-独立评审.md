## 推荐布局规格

单位均为 CSS px；画布中的对象尺寸为世界坐标，工具栏 / 控制点尺寸为屏幕坐标，缩放时保持可操作尺寸。此处是推荐桌面规格，不将静态评审文档的横向滚动误作移动端产品方案。

| 部位 | 建议规格 | 目的 |
| --- | --- | --- |
| 工作台 / 我的画布 | 导航宽 80–96；内容最大宽 1440；左右边距 32（窄窗 20）；标题 24 / 32 行高；标题到内容 24 | 入口持续可见，管理内容与编辑器的沉浸画布区别清楚 |
| 画布列表 | 卡片最小 220、最大 320；间距 24；封面 16:10；名称 16 / 24，更新时间 12 / 18 | 封面、名称、更新时间形成三层；空态与失败态分开 |
| 编辑器顶栏 | 高 56；左右 16；文档名 14 / 20，最大 240；保存文本 12 / 18；主按钮高 36 | 把工具留给画布，顶栏只承载文档行为 |
| 右侧对话 | 默认 320，允许 280–400；左右内距 16；正文 14 / 22；消息间距 20 | 2 × 2 结果缩略图约 116–176，仍能辨别内容 |
| 左侧工具栏 | 距左 16；壳宽 56；按钮 40 × 40，间距 4；图标 20；聚焦 / 悬停显示文字提示 | 保留用户确认的四个工具，避免额外模式图标挤入 |
| 底部输入 | 相对中央画布居中；默认宽 560、最大 640、最小 320；距底 20；内距 16；文字 14 / 22；最多 160 高后内部滚动 | 引用和多行输入不会不断吞掉画布；右栏收起时重新居中 |
| 生成组 | 标题 14 / 20，最多两行；状态 12 / 18；标题到状态 4，状态到容器 12；容器内边距 16；候选间距 16 | 标题与生成状态持续属于一个结果组 |
| 图片对象 | 默认展示宽 240 世界单位，按输出比例；四候选保持同高；派生结果维持源图高宽比例 | 对象不随组内数量变化而缩小 |
| 选中态 | 2px 贴边深灰线；角点 10–12px 圆；中点 20 × 8px 胶囊；隐形命中区至少 24 × 24；图片标签在上方 8 | 只选中一张，组边框保持 1px 浅灰；视觉控制点和可点击区域分开 |
| 普通浮层 | 距图下缘 12；高 48–56；内距 6；最大宽为中央画布安全区；按钮高 36–40 | 不覆盖对话栏、底部输入框和左工具栏 |
| 蒙版浮层 | 工具区可滚动；“退出”与“抠图”固定；按钮高 40，主按钮最小宽 72；状态文案距工具栏 8 | 无论宽度如何都能确认或退出当前模式 |
| 画布安全区 | 从中央画布矩形扣除左栏 88、顶内边 16、右内边 16、底部输入矩形及 16px 间隙 | 限制浮层需按真实元素几何计算，不能只用窗口宽度 |
| 点击 / 对比 | 桌面常用按钮至少 36 高，图标工具 40；触控 44 × 44；正文目标对比 4.5:1，UI 边界与焦点目标 3:1；焦点线 2px | 黑白灰仍必须靠文字、图标、线型区分状态，不能只换灰度 |
| 窄窗 | 1024–1199 右栏 280；低于 1024 可收起右栏，明确“对话”按钮与未读数；蒙版操作栏仍可见 | 这项为建议；首版桌面最小宽度与移动端范围交给主持收敛 |

## 状态样式表

| 组件与状态 | 背景 / 边框 | 文字 / 图形 | 动作及规则 |
| --- | --- | --- | --- |
| 四候选组：生成中 | 四格同一深灰底、固定尺寸 | 四格同样的加载标识；组头“正在生成 · 本轮 4 张” | 共用一个任务，不出现逐张排队、百分比或预计时间 |
| 四候选组：完成 | 图像 + 1px 组边框 | “4/4 已生成”；候选 01–04 | 单图可选；共同容器保留 |
| 四候选组：部分完成 | 有效图片保留；缺失格浅灰底、虚线框 | 组头“部分完成 · 2/4”；缺失格叹号与简短原因 | 仅终态出现；重试行为待产品 / 技术收敛，不画自动补生成 |
| 四候选组：失败 | 四个固定缺失格 | “生成失败 · 0/4”；组级原因与恢复动作 | 不删除需求；状态图标与成功图像分开 |
| 单图：选中 | 2px 贴边线 + 指定控制点 | 上方图片图标与名称；工具栏紧随该图 | 其他候选不改变尺寸 / 明暗；图片标签可追加来源 |
| 蒙版：识别中 | 原图可见、半透明遮层 | “正在识别主体选区”，不展示成功轮廓 | “抠图”禁用；识别成功才进入编辑 |
| 蒙版：可编辑 | 原图上斜线填充主体选区，轮廓实线 | “蒙版编辑”；说明点击“抠图”后生成 | 显式主按钮；画笔 / 橡皮 / 撤销 / 重做按真实可用性 |
| 蒙版：提交生成中 | 原图与蒙版保留、局部锁定层 | “正在生成透明图片” | 固定提交版本；编辑和重复提交禁用 |
| 蒙版：失败 | 原图与最近有效蒙版保留 | “透明图片生成失败”，与“识别失败”区分 | 回到编辑 / 安全重试；不自动执行 |
| 派生抠图：完成 | 棋盘透明背景 + 主体图像 | “候选 01 的抠图结果”；不使用候选序号 05 | 在源图右侧；对话卡显示来源与定位 |
| 对话：结果组 | 2 × 2 同一容器；8px 间距 | 组级状态一行，方向说明按需展开 | 一组一个定位动作；点单图能定位对应对象 |
| 对话：单图 / 视频 | 单图等比缩略；视频封面上播放图标与时长 | 名称、来源、归属画布；不存在时长数据不写占位秒数 | 视频“播放”与“定位画布”分开，播放不改变画布选择 |
| 文档 / 连接状态 | 顶栏文本；异常才显示窄条 | “保存中 / 已保存 / 保存失败”；“连接中断，状态可能未更新”独立 | 已保存与任务完成互不替代 |

## 最需要调整的三处页面

1. **S39 / S15 的组内布局。** 采用 `标题与组状态 → 固定尺寸候选横排 → 单图浮层`。插入后为 `候选 01 → 01 的抠图结果 → 候选 02 → 候选 03 → 候选 04`，只扩容不压缩。浏览器真实测量是本项依据。
2. **S14 的模式识别。** 图片左上为“蒙版编辑 · 候选 01”，画面内只叠加选区；下方依次 `退出｜画笔 橡皮 … 撤销 重做｜抠图`，最后按钮固定。模式说明在画布内可读，不能仅靠评审文档旁注解释。
3. **S16–S18 的引用到结果。** 输入引用卡显示缩略图 / 唯一来源 / 移除；右侧发送消息保留该缩略图；待确认蒙版时显示一个与画布对应的模式卡，完成时换成结果卡与定位动作。三种信息不分别占据三条重复回复。
