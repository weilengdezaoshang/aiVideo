# 字体与过渡同步检查

2026-09-09。用户要求同步字体讨论与推荐的三项调整：字体层级、大图过渡、章节滚动。

## 已同步

- 介绍页标题使用独立 `GalleryDisplay`，加载 Noto Sans SC 真正的 500 静态字重子集 `display-medium.ttf`。字体来自 Google Fonts 官方仓库，来源和授权记录在 `assets/sources.json`；原有 700 字重文件保留供其他原型界面使用。
- 首屏保持两行，字距由 -.035em 放松至 -.015em。章节标题中等字重、自然字距；桌面正文 16px / 1.8，手机副标题 14px，辅助说明 12px。
- 大图内容 200ms 淡入与轻缩放，关闭时反向 150ms，遮罩同节奏。Esc 和关闭按钮复用关闭流程，关闭后焦点返回原作品；序号使旧的结束回调失效，重复打开清理旧动画。
- 介绍页锚点采用原生平滑滚动，持续时间由浏览器决定；跨页返回指定介绍分区同样平滑定位，普通返回首屏即时定位。减少动态效果时无开合动画、章节即时定位。

本次按上一轮明确推荐的三项实施，工作台淡入留作后续可选项。
