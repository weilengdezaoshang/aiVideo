# v0.5 产品视觉原型交付检查

日期：2026-09-09。目标：[产品效果 v0.5](../../产品效果-创作平台-v0.5.html)。本轮只修改文档与原型素材，生产代码原有工作区改动保持不动。

## 本轮改动

1. 重做介绍页，采用摄影作品展示与可切换主题；进入工作台、示例画布和产品文档入口可操作。
2. 工作台、空列表、有内容列表和编辑器统一为暖白与深绿视觉。移除工作台重复标题栏。有文档时缩短欢迎区域，首屏可以看到最近文档名称和打开入口。
3. 编辑器统一图标、表单、候选图、对话预览与工具栏；主要按钮和输入字体放大，保留显式蒙版提交及来源关系。
4. 画布封面按文档 ID 映射，新增文档不会改变其他文档的演示封面。
5. PRD 和交互评审文档链接改为 v0.5；v0.4 产品原型留档。

## 实际验证

通过 Codex 浏览器访问本机 HTTP 预览，验证以下操作：

- 介绍页“山海之间”切换主图及“潮汐来信”标题。
- 介绍页 → 工作台 → 我的画布；空列表有新建入口，有文档后显示可打开的封面卡片。
- 新建并命名“自然品牌 · 创意草稿”，填写创作描述，提交四图生成演示，再送达模拟结果，画布和对话均显示四张候选。
- 选图后出现图片工具栏；点击“抠图”准备蒙版，送达模拟响应后出现画笔、橡皮与显式“抠图”。
- 蒙版栏提交并送达模拟响应后增加一张派生结果，原四张保留；返回列表并刷新后文档仍存在。
- 桌面 1280×720 检查介绍页、工作台、列表、编辑器与蒙版栏；手机 390×844 检查介绍页、工作台和列表。修正手机标题孤字换行。临时视口设置已重置。

静态检查：外层及 iframe 内各一段脚本均通过 `node --check`；静态 ID 无重复，模板标记全部替换；四张图片的文件头为 JPEG。构建输出约 8.55 MB，所有图片和字体内嵌。

## 范围

这是一份视觉与交互演示；照片为展示素材，生成与蒙版由模拟响应推进，未连接生成服务。视频、文件上传与照片真实识别仍沿用方案中的原型边界。浏览器未允许 `file:` 导航，因此本轮运行验证以 HTTP 预览为准。

本轮没有修改生产代码，未执行生产测试套件；对交付 HTML 进行了上述构建、语法、浏览器交互和视觉验证。独立视觉意见及关闭记录见 [视觉评审](./视觉评审.md)。
