# aiVideo 产品原型 v0.5 视觉规范

本文件仅约束 `docs/产品效果-创作平台-v0.5.html` 及其构建源，不覆盖仓库根目录设计规范，不代表生产界面已落地。

用户认为 v0.4 线框效果不理想，v0.5 改为完整视觉原型。当前用户已确认的方向为“专业创作工作室”：中性灰白、少量蓝色强调，默认浅色，仅编辑器可以切换深色。此确认替代前一版暖白与墨绿方案；产品范围和交互状态继续保留。介绍页最新例外见下文，未获得新的用户主题确认。

用户拒绝上一版介绍页主题并指出底部白色操作区突兀后，本轮实现暗色影像展厅作为可评审方向；异步主题偏好尚未回复，不视为用户已确认。范围仅介绍页，工作台、列表与编辑器不随本轮扩大修改。

## 表面与目的

| 页面 | 使用目的 | 设计处理 | 主题范围 |
| --- | --- | --- | --- |
| 介绍页 | 认识产品并开始体验 | 满屏作品首屏、左侧两行标题、左下缩略图与说明、首屏仅顶部创作入口；后续展示四张素材、实际原型截图与开放助手步骤 | 全页暗色影像展厅、暖白按钮；不随编辑器主题切换 |
| 工作台 | 开始或继续创作 | 模块导航与最近画布；有记录时压缩欢迎区，让文档入口出现在首屏；进入画布 Tab 后才展示列表 | 保持浅色 |
| 我的画布 | 找到、打开和新建文档 | 可辨识的封面与名称；封面按文档 ID 稳定映射；空列表有明确创建入口，新建或打开后进入编辑器 | 保持浅色 |
| 编辑器 | 比较候选、调整素材 | 点阵画布、轻工具栏、底部输入、右侧对话；不同操作状态保持清楚；返回我的画布 | 默认浅色，可主动切深色并记住偏好 |

## 视觉语言

- 场景：长时间桌面创作与日常浏览。中性界面承载素材，蓝色用于主操作、选中、焦点与少量交互强调；不把照片整体染成主题色，也不用大面积装饰色替代内容。
- 介绍页标题独立使用 `GalleryDisplay`：官方 Noto Sans SC 实例化为真正 500 字重的 `display-medium.ttf`；编辑器沿用原 `display.ttf`。首屏 h1 字距为 `-.015em`；章节 h2 字重 500、字距 0，字号按 `landing.css` 响应式规则缩放（章节 `clamp(32px,3.4vw,48px)`，桌面常见约 40–48px；收尾 `clamp(32px,4vw,52px)`）。桌面章节正文 16px / 1.8，手机首屏副标题 14px、章节正文 14px / 1.85；素材说明、截图注释与页尾备注统一 12px。 正文使用系统中文字体。首屏标题明确以“让灵感”与“自由成形。”两个 span 分两行，桌面与手机沿用该层级。编辑器主要操作 12px，输入与对话正文 14px。
- 图片展示承担视觉重心，界面减少重复边框与标签。大展示区域圆角 14–16px，操作控件 6–9px。操作栏以柔和投影表达浮层关系。
- 图标复用本仓库 Bootstrap Icons SVG；画布已有几何操作图标沿用原有工具语义。
- 焦点、选择、光标和滚动条使用统一配色；按钮提供悬停、禁用与键盘焦点。减少动态效果设置下禁用按钮过渡。

## 介绍页构图与交互

本轮按用户要求参考已观察到的 [即梦官方介绍页](https://jimeng.jianying.com/) 首屏作品构图，保留 aiVideo 品牌及已有 Unsplash 素材。后续功能区围绕本项目的四方向、画布与助手组织，不宣称已核验即梦后续章节的视觉。此参考不涉及即梦媒体、标识或视频能力宣称，也不扩展本产品既定能力。

1. 首屏为满屏作品背景，左侧两行显示“让灵感 / 自由成形。”与产品范围短句；左侧遮罩保障阅读，首屏唯一主入口为顶部右侧暖白“开始创作”按钮，不保留底部白色操作卡或伪输入框。左下横排缩略图及当前作品说明。海洋、建筑、花卉三个缩略图由用户主动切换背景、替代文本和说明，选中态可辨；不自动轮播、不播放视频。
2. 图片创作区以四张展示素材说明视觉可能，点击任意卡片打开原生 `dialog` 大图。素材用途与非同一提示词生成结果的说明可见；支持关闭按钮、Esc 和回到原触发卡片的焦点。
3. 智能画布区展示当前产品原型的真实编辑器截图；截图与按钮均进入 `example` 路由，不把静态截图伪装成正在运行的画布。
4. 创作助手区为静态步骤示意：明确引用图片、准备并调整蒙版、等待用户在蒙版栏点击“抠图”。介绍页浏览不调用模型，不自动创建文档；进入示例沿用已有本机示例行为。
5. 全页采用深炭灰背景、暖白文字与按钮，原色作品贯穿章节；实际浅色编辑器截图作为展品保留，助手以开放步骤呈现。这些是介绍页自身构图，不受编辑器深色偏好控制；工作台、列表及编辑器行为保持原规则。

窄屏重排场景缩略图与作品网格，双行标题按可用宽度适配。默认内容静态可见。首屏仅首次进入以 WAAPI 展示图片 1000ms 缩放与标题两行 620ms 错开入场；图库及实际界面图通过 IntersectionObserver 首次进入视口时各播放一次。三层场景图片先 decode，再以请求序号防止快速点击乱序，切换 active class 触发 650ms opacity 过渡，同时同步 aria-hidden、说明和选中态。后台、离开介绍页或 pagehide 时取消动画、断开观察并作废待完成切换；减少动态偏好即时取消动画和过渡，重新允许动态不重播首屏。悬停放大仅在 hover:hover 且 pointer:fine 时启用，无自动轮播。章节链接与产品路由协调，跨页仍经过编辑器离开保护。

大图预览新增 200ms 进入、150ms 退出，以 opacity 与 scale(.98) 配合遮罩同节奏变化；Esc 与关闭按钮共用退出流程，完成后恢复触发卡片焦点。反复打开时取消旧动画，并用序号防止旧关闭回调关闭新预览；减少动态偏好下直接关闭。章节采用 CSS 原生 `scroll-behavior:smooth`，减少动态时为 `auto`；跨页返回介绍章节平滑定位，返回介绍首屏即时定位。跨页仍经过既有离开保护。本轮不增加工作台淡入。

## 共享主题 tokens

外层产品壳与 iframe 使用同一份 [theme.css](./visual-src/theme.css)。以下为当前原型约定；生产实现迁移时保留 token 语义，不复制多套颜色常量。

| Token | 浅色 | 编辑器深色 | 使用位置 |
| --- | --- | --- | --- |
| `--studio-bg` | `#F5F5F7` | `#191A1E` | 页面 / 画布底色 |
| `--studio-panel` | `#FFFFFF` | `#25262C` | 顶栏、侧栏、输入、对话、浮层 |
| `--studio-ink` | `#202124` | `#F0F1F4` | 主要文字 |
| `--studio-accent` | `#356DF3` | `#356DF3` | 主按钮、选框、键盘焦点 |
| `--studio-soft` | `#EFEFF2` | `#30323A` | 次级面板 / 控件底色 |
| `--studio-muted` | `#60646C` | `#B2B6C0` | 辅助文字 |
| `--studio-line` | `#DEDFE4` | `#41444F` | 必要分界线 |
| `--studio-selected` | `#EAF0FF` | `#293958` | 被选工具 / 导航底色 |
| `--studio-selected-ink` | `#2456C8` | `#ADC5FF` | 选中区域文字 |

生成中、部分完成、失败、结果待确认继续同时依靠文字与形态区分；深色不能让错误格、选框、蒙版或透明棋盘消失。正文对比目标 4.5:1，控件与选框目标 3:1；这是检查要求，不代表本次已逐项测得通过。

## 编辑器主题行为与验收要求

1. 无偏好时编辑器使用浅色；只有编辑器显示浅色 / 深色切换入口。工作台与列表始终浅色；介绍页使用独立的暗色影像展厅，不与该开关联动。
2. 记录显式选择的偏好，重新打开编辑器时沿用；返回浅色页面不覆盖已记住的编辑器偏好。原型使用独立键 `aivideo-editor-theme-v1`，不混入画布数据或草稿。
3. 切换只更新 DOM 的 `data-editor-theme` 与 CSS tokens，不重建画布状态、不调用 `render()` 重置编辑会话、不改写素材、任务、会话与文档。四候选尺寸和 24px 间距不随主题改变。
4. 在未发送文本、已有引用、单图选中、蒙版有未提交笔画、生成中和结果待确认等状态切换后，草稿、引用、选择、笔画、任务标识和位置应保持一致。切换不得触发模型调用、模拟响应或蒙版提交。
5. 原型外层通过 `product-theme` 消息同步 iframe；两层只有在当前页面是编辑器时应用深色。校验消息来源与 `light` / `dark` 值；切换不重载 iframe。

上述是本轮同步后的设计与验收约定；HTML 中的主题机制属于原型实现，生产界面尚未落地，本机原型抽样验证结果见 [主题同步检查](./主题同步检查.md)，不代替生产验收。

## 内容与交互约束

照片是公开授权的展示素材，必须保持“演示素材”“演示封面”等用途说明，不代表当前提示词或模型的输出质量。进入蒙版编辑时显示操作示意，不用几何遮罩伪装照片真实抠图。

复用 v0.4 的文档、四方向、蒙版、派生关系与模拟响应状态机。新样式不改变 148px 候选与 24px 间距。真实生成、视频播放、文件导入、照片主体识别与生产持久化不在此原型中实现。

手机端重排介绍页、工作台与列表；编辑器按桌面工作区展示并提供横向查看说明。

## 即梦参考：章节连续性补充

介绍页导航固定在顶部：首屏透明，滚动超过 24px 后在 220ms 内转为深炭灰背景。桌面高 84px，手机高 72px，章节锚点保留相同顶部偏移；当前章节以细下划线与 aria-current 标记。图片区标题和助手文案首次进入视口时以 440ms 淡入、轻移展开。进入工作台等产品页时立即完成路由切换，再用 200ms 淡入衔接；不等待退场动画，不阻挡操作。减少动态效果下直接呈现。参见 [章节过渡检查](./章节过渡检查.md)。
