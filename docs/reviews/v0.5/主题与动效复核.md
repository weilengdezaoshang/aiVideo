# 主题与动效定点复核

复核范围：`visual-src/landing.js`、`landing.html`、`landing.css` 与 `product-shell.html` 的介绍页生命周期。只读实现，以 Node VM 的 DOM、媒体偏好和 IntersectionObserver 替身验证行为；未用浏览器评估最终视觉表现。

## 结论

本次限定范围内未发现必须修复的问题。三层作品 DOM、`is-scene-active` 650ms 不透明度过渡与脚本契约已经匹配。首屏白色操作卡移除后，作品说明节点仍需保留，现有脚本依赖 `landing-scene-copy`。

## 已验证

- 两次切换按相反顺序完成 decode：较早请求不会覆盖较新的作品。
- decode 等待期间离开介绍页：请求失效，作品不被异步改写；所有已创建的动画被取消，观察器断开。
- 重新进入介绍页：不会重复首次背景和两行标题的入场动画。
- 动态启用 reduced motion：暂停标记开启，观察器断开；重新允许动效后不重播首屏。CSS 同时关闭作品过渡与其他动画。
- 浏览器标签页转后台：取消动效并使待完成请求失效；返回前台不重播首屏。
- pagehide/pageshow：停止与恢复生命周期有效，首屏不重复播放。
- 路由 reveal 在更新 hidden 后发送 landing-visibility，脚本读取到的可见状态正确。

Node VM 验证全部通过。测试替身不能验证 CSS 合成过程或实机帧率；最终视觉验收应留意快速交替点选三张作品时的交叠效果，以及移动端标题与缩略图布局。没有为本次复核增加生产代码或 UI 修改。
