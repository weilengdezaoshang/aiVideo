# 即梦参考介绍页检查

日期：2026-09-09。用户要求“这介绍参考即梦的”。本轮更新独立产品原型的介绍页，维持 v0.5 地址与既有画布体验。

## 参考与改动

实际查看 [即梦官方介绍页](https://jimeng.jianying.com/) 的首屏，采用满屏作品、透明顶栏、居中大标题、场景缩略图和底部创作入口的构图。当前实现使用 aiVideo 品牌与已有公开展示照片，不使用即梦媒体；背景是可手动切换的静态图片。

- 首屏提供海洋、空间、花卉三种场景，切换时同步图片、替代文本、说明和选中状态。
- 四张作品点击后打开大图；关闭或 Escape 返回触发按钮，弹层也可直接进入示例画布。
- 画布介绍使用当前原型的实际界面截图，点击进入完整交互；助手区展示明确引用、准备蒙版、显式提交的协作步骤。
- 顶部导航定位图片、画布、助手三个介绍分区；各主要按钮通向工作台或示例编辑器。
- 手机端首屏、双列作品、图片预览与产品介绍重新排版。介绍正文采用中性浅色，作品首屏和深色收尾不受编辑器主题偏好影响。

## 实现与边界

介绍内容拆分到 `visual-src/landing.html`、`landing.css`、`landing.js`，由 `build.py` 与既有产品壳组装。图片、字体与编辑器截图内嵌到单文件；原型运行不依赖远端媒体。素材出处见 [sources.json](./visual-src/assets/sources.json)。

分区路由恢复通过既有 iframe 导航请求处理，保留保存失败时的离开保护。原生 dialog 负责模态焦点，JavaScript 补充关闭后的焦点返回。场景切换只更新展示，不创建文档或调用模型。

本轮是介绍页与文档交付，未修改生产前后端。展示照片不代表生成质量；真实生成、视频播放和生产接口实现仍按技术方案推进。既有编辑器主题评审保留为其时点记录，本报告不重新宣称编辑器全量验收。
