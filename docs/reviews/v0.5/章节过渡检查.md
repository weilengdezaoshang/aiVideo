# 章节过渡检查

2026-09-09。按用户要求再次查看 [即梦官网](https://jimeng.jianying.com/)：实际观察首屏媒体、滚动后仍在顶部的导航，以及下一章节的大幅媒体和分段文案。借鉴导航与章节连续性，继续使用本项目自身素材与能力说明。

## 改动

- 固定导航从透明背景过渡到深炭灰，220ms；当前章节细下划线过渡200ms，附 aria-current。
- 图片区标题与助手介绍文案首次进入视口时，440ms 淡入及12px轻移；默认内容可见，返回不反复播放。
- 从介绍页进入工作台、示例等产品页时，立即切换路由，产品区200ms淡入；新切页与动态偏好变化取消旧动画。
- 使用原生 CSS、WAAPI 和一次性观察器；保留减少动态效果分支，无滚轮劫持、自动轮播或新增生成调用。

## 首屏构图与滚动衔接补充

首屏调整为居中标题，桌面右侧纵向切换作品、手机横向排列。底部保留探索入口，图片创作章节标题居中，并缩短章节间空白。

首屏背景随滚动最多下移 100px，标题最多下移 48px 并逐步淡出；以原生滚动进度驱动，不劫持滚轮，回滚立即恢复。底部渐变接入作品区背景，下一章节延续原有标题与作品入场动画。减少动态效果时清除位移及淡出；离页、隐藏时清理。

浏览器验证：桌面首屏构图、滚动后标题透明度归零、背景位移达到上限、页面无横向溢出。


## 最新替换：幕布收拢

替换上一版背景视差和标题淡出。以首屏滚动进度驱动整体画幅的左右裁切和圆角，桌面每侧最多 7%、手机 4%，圆角最大 32px；原生滚动到首屏高度的 65% 时完成收拢。文字不单独淡出，下一章节沿既有布局进入。回滚反向恢复，减少动态效果、隐藏和离页时清除裁切。此规则取代上节的 100px / 48px 位移。


## 最新替换：下一幕上移覆盖

移除幕布裁切及控件位移。首屏在额外 45svh 的容器内使用原生 sticky 短暂停留，图片创作模块以不透明背景和顶部圆角从下方覆盖。滚动不被截获，可随时反向；减少动态效果时退化为普通连续布局。此规则取代上一节幕布收拢。
