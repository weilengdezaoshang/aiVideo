## 共用交互

1. 选中状态有轮廓、节点重命名与标签入口。媒体节点选中后，两侧出现创建连接节点入口。文本观察到右侧入口。
2. 单选媒体时，菜单与生成器是两个不同界面，可同时出现；不能因菜单出现而把生成器关掉。
3. 空媒体节点只显示该类型生成器，不能给它套用成品工具栏。
4. 图片和视频生成器的内容来自该节点已有输入：切换节点会切换提示词与参数，而非覆盖到全局共用草稿。
5. 时间线是可在画布直接编辑的节点，不能把右侧时间线面板当作严格复刻。
6. 取消选择会退出节点菜单与生成器。全局Agent对话入口单独存在。
7. 浮动菜单/生成器实际位于选中节点附近。拖动、缩放、窗口变化、长菜单避让的精确定位规则和时长仍待录屏验证。
8. 视频素材预览在观察时出现缓冲状态；不把播放成功列为已验证。

## 当前项目偏差

源码范围：apps/web/canvas/app.tsx、panels.css、panel-presence.tsx、state/commands.ts、timeline-studio.tsx。

- app.tsx 的 selectedObjectId effect 把所有单选都导向右侧属性/时间线面板；这会令 ComposerPresence 隐藏生成器。
- canvas-selection-tools 固定 top:68px / left:50%，共用连线、抠图、重绘、撤销、重做、删除。菜单既不按元素类型分流，也不锚定选区。
- 生成器需要先在属性面板点“编辑生成参数”才绑定节点，即梦单选媒体时直接显示。
- 全局生成器在无选择时仍出现，与本次核对的即梦画布不同。
- 多选仍展示单元素通用工具，没有节点计数、布局与编组菜单。
- 文本/时间线都被当作属性栏内容，缺少文本背景菜单与画布内时间线编辑。
- 现有节点草稿、引用、识别取消、时间线数据、生成请求幂等可继续复用；不能为视觉还原移除这些行为。

## 实施拆分

### 一、选择状态与浮层归属

用显式类型建模 none / image-empty / image-ready / video-empty / video-ready / text / timeline / multi / processing / error / board-extension。以文档对象、选中数量和生成状态共同判定，不只看kind。菜单、生成器、内联编辑器、Agent侧栏的显示统一由该状态派生。

单选媒体自动绑定该节点草稿；切换前先保存旧节点；无选中/多选/文本/时间线不显示媒体生成器。打开Agent面板时隐藏节点生成器，关闭后恢复当前节点编辑状态；仍遵守用户明确要求的侧栏与输入互斥。

### 二、浮动工具栏与生成器

工具栏按以上实测顺序和分组实现；从世界坐标投影到画布视口，在对象预览变化、相机变化时同步定位。测量真实浮层尺寸后避开顶栏、左栏、视口边界与Agent面板，长菜单不能溢出。浮层指针操作不触发画布取消选择。

图片/视频分别使用自己的参考区、参数行和提示词；图片结果节点还原原生成输入，上传素材/空节点使用对应草稿。参考图、生成对象与编辑对象身份显式区分，避免把当前输出静默追加为原参考。

### 三、文本、时间线、多选

文本做背景色弹层和原位编辑。时间线复用独立timelineNodeStore与TimelineStudio业务逻辑，呈现为节点内嵌展开/全屏编辑；不同节点数据不能串用。多选独立工具栏，编组需新增可撤销命令，布局需根据已测菜单区分宫格/智能布局；当前groupId是生成组身份，不能直接冒充用户编组。

### 四、真实动作与后端缺口

现有能力能接入：图片生成、视频生成、引用、抠图/蒙版、局部重绘、下载、文本编辑、时间线裁剪/分割/导出。

需另查Provider和后端协议：720全景、智能超清、多角度、智能打光、消除、局部重拍、视频编辑、视频修剪独立产物、首尾帧/全能参考、批量处理。不能把这些菜单映射成普通文生图并声称功能等价。精确还原的UI规格与真实动作接入分别验收。
