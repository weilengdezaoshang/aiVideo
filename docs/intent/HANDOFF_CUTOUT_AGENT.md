# 转交：抠图接入 Host Agent（默认自动 · 高风险才确认）

> 日期：2026-10-17（交互修订）  
> 仓库：aiVideo  
> 依据：`docs/cutout-flow.md`、`NOTES_CUTOUT_AGENT.md`、用户反馈「少点、高风险才拦」

---

## 一句话

对话命中抠图 → **不走 Provider** → detect 识别主体 → **低风险自动 apply** → 透明图落画布并回写；**仅高风险**才在右侧预览拦一下或下画布改蒙版。

---

## 产品原则

1. **默认零点击**：用户说「帮我抠图 / 抠出里面的人」且条件安全 → detect 完直接 apply，过程条只展示进度与结果缩略图，可撤销。
2. **高风险才人工**：不确定主体、多主体、用户要精细改边、置信度低 → 才出现「确认 / 去画布修正」。
3. **画布工具条是兜底**，不是主路径日常步骤。
4. 仍禁止：Provider 冒充抠图；付费/不可逆动作静默提交（抠图本身不扣积分，但自动 apply 必须可撤销）。

---

## 风险闸门（何时拦人）

| 信号 | 判定 | 行为 |
|------|------|------|
| 无选中图 / 源图失效 | 高 | clarify，不 detect |
| 单主体人像 + mask 质量够 + 用户说「抠人/去背景」且未提精细 | **低** | **自动 apply** |
| 用户说「精细抠 / 发丝 / 我改一下」 | 高 | detect 后进画布蒙版，等人点「抠图」 |
| 多主体 / 主体个数不确定 / 「抠左边那个」但未点选 | 高 | 右侧预览 + 选主体或 clarify；未点选不自动 |
| mask 过碎、面积异常、detect 失败/429 | 高 | 预览失败态 + 重试 / 去画布手涂 |
| 「先抠再视频」等顺位 | P0 clarify；不自动连跑 | |
| 历史 SSE / 刷新重放 | — | **不**自动 apply；可点「同步结果」或「再抠一次」 |

**默认策略**：能判低风险就自动；判不清当高风险（fail-closed 对人，不是对系统静默乱抠）。

---

## 主路径交互（用户感知）

### A. 低风险（目标：全程不用点）

1. 用户：选中图 +「帮我抠出里面的人」
2. 右侧过程：识别中… → 正在抠图… → 完成（缩略图 +「已放到画布」）
3. 画布：自动出现透明 PNG；**不弹工具条**
4. 可选轻反馈：结果旁「撤销本次抠图」（一次命令撤销）

### B. 高风险（才出现交互）

1. detect 后右侧出现 **主体预览**（轮廓/缩略）
2. 两个动作即可：
   - **确认抠图** → apply（仍不必展开完整工具条）
   - **去画布修正** → 打开现有 CutoutControls（画笔/橡皮/点「抠图」）
3. 多主体：预览里点选一个再确认（P1）；P0 可先 clarify「图里有多人，请点选或说明」

### C. 过程条信息（对齐 Codex 折叠）

- 折叠默认只显示：意图「抠图」→ 状态（识别/自动合成/待确认/完成）
- 展开才见 detect/apply 细节；低风险路径无「等待你点击」步骤

## 复制给实现 Agent

```text
你是 aiVideo Host「抠图接入」实现 Agent。中文注释。

# 目标（交互修订 2026-10-17）
「帮我抠图」等 → image_edit + op=matting → rembg detect/apply。
默认：低风险 detect 成功后 **自动 apply**，用户无需点「抠图」。
高风险：右侧主体预览 →「确认」或「去画布修正」；画布工具条仅兜底。
禁止 Provider 冒充；自动 apply 必须可撤销。

# 风险判定（实现为纯函数 cutout_risk(decision, image_meta, mask_stats)）
低风险需同时满足：有有效源图；主体意图清晰（人/去背景/透明底）；未要求精细手改；mask 质量启发式通过（连通域≈1、面积比例在阈值内）；非多主体点选句。
否则高风险。判不清 → 高风险。

# 要做
1. Host：matting 命中后仍 canvasAction，但增加 mode=auto|confirm（由风险闸门写入）。
2. 前端：mode=auto → detect 成功直接 apply + 回写 run，不打开 CutoutControls；失败降级 confirm。
3. mode=confirm → 右侧预览卡（确认 / 去修正）；去修正才 openAgentCutout 工具条。
4. 撤销：apply 结果走统一命令，支持一键撤销本次派生图。
5. 收敛正则与 slots.op=matting；「先抠再视频」P0 clarify。
6. Trace：risk、mode、auto_applied、user_confirmed。
7. 测试：低风险零点击 K；高风险必现确认 K；自动路径失败降级；撤销。

# 非目标
- P0 不做完整多主体点选 UI（可先 clarify）
- 不做对话内画笔
- 不重做 rembg

# 验收
K-A1 单人像 +「抠出里面的人」→ 无工具条、无二次点击 → 透明图上画布 + run completed
K-A2 结果可撤销，撤销后源图在、派生图消失
K-H1 「精细抠发丝」→ 不出现自动 apply，须确认或画布修正
K-H2 无图 → clarify，不 detect
K-H3 detect 失败 → 可重试，不静默空结果
K-S1 「先抠再视频」→ clarify
K-X1 不出现 Provider image_edit 作业
```

## 与旧铁律的关系

旧文档「禁止跳过抠图按钮」改为：

- **禁止在高风险或用户要求手改时自动 apply**
- **低风险允许自动 apply**，且必须可撤销、过程可见
- 画布「抠图」按钮保留给修正路径
