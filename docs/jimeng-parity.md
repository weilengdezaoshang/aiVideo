# 即梦功能对标与实施验收

更新：2026-09-14。目标：根据即梦的功能补全当前项目缺少的功能，重点包括画布连线、时间线和 Agent 创作。本文是持续实施清单，不以完成某一阶段替代整个目标。

## 范围与证据

已核对源码：画布节点支持引用选择、生成快照和来源记录；生成具备请求幂等、取消、状态恢复；Agent 当前主要为引用单图后的抠图流程；未找到成片时间线、结构化分镜、配音音乐和合成导出模块。

公开功能参考（检索于 2026-09-13）：

- https://jimeng.jianying.com/ai-tool/home?activeTab=activity ：Agent、输入剧本与参考、主体、Skills、音乐与配音入口。
- https://www.sina.cn/news/detail/5296009233043655.html ：即梦官方微博 2026-05-07 公告，文档与分镜手动编辑、流程可视化和暂停。
- https://www.jimeng.com/ ：图片和视频生成、首尾帧、局部重绘、扩图、消除、抠图。

完整多轨剪辑能力未经即梦公开资料证实，时间线作为本项目用户明确提出的成片能力实现。不能把候选四方向图片当作分镜，也不能把 Mock 产物当成真实模型验收。既有抠图蒙版显式提交和未知付费请求不自动重提的约束继续生效。

## 实施顺序

1. 画布引用关系可视化与可操作关系，复用已有引用/谱系，不建立第二套不一致的数据。
2. 结构化镜头和时间线数据、文档兼容、统一命令；基础编辑与实际预览/导出。
3. Agent 分镜规划、工具执行、任务状态恢复和自动组装时间线。
4. 对话局部修改、锁定与版本、主体复用、音频与字幕、成本显示和 Skills。
5. 补齐图片/视频可控生成差异，真实 Provider 验收与完整创作回归。

## 整体验收场景

输入“做一条 30 秒产品广告”，编辑 Agent 生成的大纲与分镜，引用产品/角色/场景素材，逐镜生成、选择版本，自动进入时间线，添加配音、音乐与字幕，调整节奏，指定只重做第二镜，恢复已保存项目并导出视频。导出内容必须与预览一致；手动编辑不被后台任务覆盖；刷新不会重复扣费提交；任何步骤失败都保留已有资产且可继续。

还需要分别验证图片编辑、视频首尾帧与参考、主体复用、Skills、画布连线操作，不能用一条顺利跑通的广告替代全部能力的验收。

## 2026-09-14 第二轮：基础时间线

- 顶栏增加时间线入口，底部可收起的编辑区，沿用编辑器浅色/深色语义变量；画布与对话区域随面板占位缩小。
- 新增帧级片段模型（30fps、画幅、素材快照、入出点）、总时长和源帧定位。第一版为顺序单轨，尚不支持多轨叠加。
- 从画布加入图片或视频；图片默认 5 秒，可调整至 1 小时；视频通过浏览器实际元数据确定裁剪边界，不把生成请求时长冒充真实素材时长。
- 支持拖动排序、前后移动、数值入出点裁剪、播放头分割、复制、删除、撤销/重做、横竖方画幅和轨道缩放；片段名称使用文本节点，避免 HTML 注入。
- 素材快照独立于画布节点，删除画布对象不删除剪辑素材；来源文件真正缺失时预览显示错误。时间线状态与画布共用命令和自动保存机制。
- 服务端验证版本、帧率、画幅、片段数量、重复 ID、素材类型/地址及帧范围，错误保存不覆盖原文档；旧客户端未提交 timeline 字段时保留，显式 null 用于撤销首次创建。
- 浏览器验证：加入品牌图 5 秒，延长为 8 秒，在 3 秒处分割，刷新恢复后保留 3+5 秒；临时 FFmpeg 生成真实 H.264 四秒素材，读取时长、加入后总长 12 秒、时间线视频播放均成功。

## 2026-09-14 第三轮：实际 MP4 成片导出

- 新增持久化导出任务 API：POST `/api/exports`、GET/DELETE `/api/exports/{id}`、GET `/api/exports/{id}/download`。任务使用不可变时间线快照和请求 UUID，同 ID 同内容返回同任务，不同内容返回 409。
- FFmpeg 执行使用独立异步进程、单渲染槽位和最多 5 项排队；任务进度来自完成的片段。取消会等待子进程退出和文件复制结束后清理临时文件；重启将中断任务标记失败，不偷偷重做。
- 统一画幅、30fps、黑色补边、H.264；视频按照源入出点裁剪、保留原声，图片及无声视频补静音。中间 MOV 使用 PCM 音轨，最终仅做一次 AAC 编码，避免分段 AAC 延迟导致拼接多帧。
- 源文件仅解析资产库与历史图片目录中的本地媒体，复制到任务工作区；禁止直接渲染任意外部 URL/文件路径，限制 FFmpeg 输入协议和视频容器。外部地址素材需先导入资产库。
- 本轮支持最多 200 个片段、总时长 1 小时；时间线多轨、转场、字幕仍待后续，不把单轨导出作为完整剪辑能力。
- 运行时 `imageio-ffmpeg==0.6.0` 已加入直接依赖及约束，优先使用系统 FFmpeg，否则使用包内二进制；Docker 沿用 requirements 安装路径。
- 时间线增加导出、取消、进度、下载链接和刷新恢复；文案明确下载对应提交时的版本。修复已保存自定义画幅不在预设时显示为空的问题。
- 真实解码测试验证图片 1+2 秒导出恰好 90 帧、29/30 帧处的颜色切换，视频 1–2 秒裁剪恰好 30 帧，并比较导出首帧与源一秒处画面；另验证真实音频存在、请求幂等、取消、重启恢复和 API 下载文件。
- 浏览器验证了三秒时间线提交、完成状态、下载链接，以及刷新后恢复相同链接和 640×360 画幅。
- 新增 6 项后端真实渲染/API 测试和 1 项前端提交/下载测试。`npm run verify` 通过：前端 166 项、后端 221 项，只有既有 Starlette 弃用警告。最终自定义画幅修复另通过类型检查/构建/lint 与 2 项界面测试；新增运行中取消检查后，6 项导出定向测试全部通过（该新增项晚于完整回归收集，因此不计入 221）。
- 整体剩余：多轨音频字幕、Agent 结构化分镜与工具执行、主体与版本、可控生成补齐等，仍以完整功能矩阵验收。

## 第四十四轮：分镜服务端顺序执行前端迁移、归属回填与自动装配

实现状态说明：本轮主流程“分镜 → 服务端生成 → 结果回填 → 自动装配时间线”已实现并通过隔离 Mock 实例浏览器端到端验收；全程未验证真实模型效果，规划与逐镜生成的真实模型质量仍属未验收。

### 前端迁移到服务端执行

- 分镜面板“顺序生成、暂停、继续、取消、重试当前镜头”全部改调服务端执行 API；删除浏览器旧执行器 storyboard-runner.ts，两条执行路径不再可能同时推进同一组镜头。
- 旧版 localStorage 执行记录保留并在面板显示一次性说明（已停止旧调度，已提交任务仍在服务端完成），不自动重放。
- 启动流程按序执行：校验镜头关联/锁定/待处理任务 → prepareNode 逐镜准备参数（模型/画幅/参考图/时长）→ ensureSaved 确认落盘 → 复查异步准备期间分镜未变化 → 生成执行标识与逐镜请求标识，提交不可变快照。
- 服务端 409（项目已有执行）时前端按项目发现并接管已有执行；提交响应丢失时保留原执行标识于本地，确认操作幂等复用同一标识，不重复提交。
- 新增 `GET /api/storyboards/runs?documentId=`：刷新/换标签页按项目发现执行记录，不再依赖 localStorage；页面关闭只停止前端轮询，服务端继续执行。

### 执行归属与结果回填

- NodeRun 新增 runId 归属字段：执行覆盖的待生成节点带归属标记，单节点入口（生成/确认结果）被既有 busy 校验阻止，杜绝待执行镜头被再次提交。
- node-generation 保护：runId 归属节点的完成任务事件不直接落位（由执行控制器核对后回填）、404 不标记 uncertain、SSE 断连不误标、节点删除/撤销不误取消分镜请求（曾归属请求集合持久记录）。
- 回填核对项目、镜头关联、节点、请求标识与参数版本：全部匹配才写入选用结果；不匹配（镜头换版本、参数被改、节点重建）的结果保留为面板可见的“未回填结果”列表（含原因与产物链接），不覆盖手动修改也不静默丢弃。
- 浏览器离线期间完成的结果在恢复后由轮询回填；SSE 与轮询重复到达按请求标识与节点状态去重，乱序迟到结果按上述核对拒绝。

### 服务端执行器补齐（审计后实现，非直接验收既有 API）

- 新增 retry 动作：失败镜头重试创建新的尝试标识并保留旧结果与旧记录于 step.attempts；unknown 镜头重试先经 jobs.resume 只查询上游，绝不重新调用模型。
- 取消只处理本轮步骤归属的任务（含提交已创建但 jobId 未记录的请求，经 requestId 兜底查找），用户单独提交的任务不受影响；取消前等待执行任务真正停止。
- check_shot 增强：参考图资产与草稿一致性、节点存在进行中任务（不同请求）拒绝启动，防止同一节点双份生成。
- control 改为异步并等待取消传播，避免取消与提交竞态留下无人认领的任务；服务重启恢复为暂停的语义保持并由测试固定。

### 完成后自动装配时间线

- 执行存在时面板提供“完成后装配时间线”选项，默认开启、提交前可关闭（按执行记录持久化偏好）。
- 全部镜头完成后按本轮执行顺序装配：使用选用结果、台词与计划时长，复用素材存在与视频实际时长校验，保留已有时间线内容（追加），一次装配为一条可撤销命令。
- 幂等：片段 source 写入 runId/shotId 标识 + 本地装配墓碑；刷新、重复轮询、重复结果不会重复追加；用户撤销装配后轮询与刷新都不再自动追加（仅显式手动装配可再次追加）。
- 执行期间时间线被手动修改（或无法确认基线）时，不自动覆盖，展示“追加装配时间线”由用户选择；素材缺失或视频不足计划时长时明确报错并保留待装配入口。
