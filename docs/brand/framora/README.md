# 帧序 FRAMORA

> 2026-09-10 公开初筛未通过：发现同名 AI 视频应用和 AI 图像服务，撤回 FRAMORA 商业正式名称建议。本目录保留设计过程，不能作为品牌权利已清查的证明。详见 [风险初筛](clearance-review.md)。

品牌提案：AI 视觉创作平台。

品牌口号：让灵感，成为作品。

“帧”连接图像与视频，“序”代表有组织的创作过程。FRAMORA 是围绕 Frame 构造的英文品牌词。

Logo 将字母 F 与错位画框结合，表达从想法到画面、从单帧到连续创作。初稿采用朱橙；当前项目采用黑白品牌方案，Logo 与品牌文字通过 currentColor 共用页面前景色，随画布深浅主题切换。

展示稿：brand-identity.png，包含主标志、单色、反白及应用图标效果。此文件为栅格品牌概念稿；现已将几何标志重绘为 SVG，并接入官网、工作台、画布和旧版入口。名称尚未进行商标及域名可用性核验。

生成方式：内置 image_gen 工具，初稿后进行一次平面化与对比度修订。完整提示词见 prompts.md。
