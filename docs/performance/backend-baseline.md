# 后端本地性能基线 · 2026-10-04

## 复跑

```sh
.venv/bin/python scripts/perf/backend_baseline.py
```

脚本使用临时目录、显式 Mock 配置和随机回环端口；客户端关闭环境代理；退出终止测试服务并清理临时数据。不会加载仓库 config.json 或调用真实 Provider。

## 测量范围

默认文件版 API，独立 Uvicorn 进程、真实 HTTP。每份画布含 100000 个 ASCII 文本字符，实际文件约 100202 字节。10/100/1000 份画布约 1/10/100 MB。微基准与串行 HTTP 每项 20 次；混合请求为 5 轮、每轮 4 个文档列表请求和 4 个健康请求，并发数 8。生成使用 64×64 Mock 图片，周期性健康检查观察保存期间的阻塞。JSON 重写含 fsync。

Python、系统、CPU 数、Git revision、dirty 状态和逐次样本见同目录 JSON。最终复跑在 verify 结束后执行，未控制其他宿主机活动；使用暖文件缓存。P95 仅为本次小样本的经验分位数。

## 解释与边界

文档增加时，保存结果和文档列表耗时近似线性增长。混合负载拖慢本身不读取画布的健康接口；生成落盘时也观察到长时间健康请求延迟。与 storage.History.save 全文档引用扫描、同步持久化在事件循环执行的源码路径一致。

吞吐数字仅对应上述短时混合读取负载，不是最大容量。单次 Mock 完成时间不代表真实模型速度。未测生产 PostgreSQL、RabbitMQ、Redis、通知/SSE 扇出、多实例吞吐、实际媒体大小和真实模型延迟，也未收集 CPU/RSS 时间序列。本次 Docker socket 在沙箱内不可访问，未连接或修改既有基础设施。
